# VoiceOver Launcher

Launcher de los addons y packs de voces de **AI VoiceOver** para World of Warcraft.

- Descarga: en **[Releases](../../releases/latest)**, el archivo `VoiceOver-Launcher-Setup-<versión>.exe`.
- Para usarlo hace falta ser miembro de nuestro [Patreon](https://www.patreon.com/NeoAuras); la membresía gratuita también sirve.
- Se actualiza solo: cuando sale una versión nueva, el launcher la descarga y ofrece reiniciar.

Windows puede avisar de que el instalador no está firmado: «Más información» → «Ejecutar de todas formas».
